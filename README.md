# mod_exiticket

A small Moodle activity for end-of-class formative reflection.

Teachers configure two or three short open questions. Each student submits one private response, optionally editable until a closing time. Teachers receive an activity report with submission totals, pending students, response rate, and answers grouped by question.

The course activity index also works as a per-class overview because each Exit ticket instance represents one lesson or class meeting.
